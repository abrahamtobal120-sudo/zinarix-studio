FFmpeg / FFprobe in Zinarix Studio
==================================

Zinarix Studio (GNU GPL v3 or later) ships two separate programs in this folder:
ffmpeg and ffprobe, from the FFmpeg project (https://ffmpeg.org).
Zinarix runs them as independent programs; it does not link to them.

These builds include GPL components (for example libx264 and libx265),
so they are distributed under the GNU General Public License,
version 3 or later. The full text is in COPYING.GPLv3.txt, next to this
file. You may copy, change and share these programs under that license.
Zinarix Studio itself is under the same license (see its LICENSE file).

Builds included
---------------
ffmpeg 6.1.1 (npm package ffmpeg-static 5.3.0, release b6.1.1)
  Windows x64 : 6.1.1 "essentials" build by gyan.dev
                source: https://github.com/FFmpeg/FFmpeg/commit/e38092ef93
  Linux       : 6.1.1 static build by John Van Sickle (johnvansickle.com)
  macOS       : 6.1.1 build used by ffmpeg-static (evermeet.cx / osxexperts)
  Build notes and configuration for each platform:
    https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1

ffprobe 4.0.2 (npm package ffprobe-static 3.1.0)
  https://github.com/joshwnj/ffprobe-static
